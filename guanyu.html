关于本站 设计说明

一个由学生团队独立完成的静态网站作品：从史料梳理、视觉设计、SVG 插画到手写代码，全部原创。这一页说明我们的设计思路、技术架构、原创声明与参考资料。

  • 页面数量9 个
  • 技术形态纯静态 HTML/CSS/JS
  • 外部依赖0

壹 · 设计理念

为什么叫“陇原星火”

“陇原”是甘肃；“星火”是南梁窑洞里的那盏灯，也是长征路上一个一个传下去的火把。我们想做的不是一座陈列馆，而是一条可以走下去的线索——所以整站以“山河—星火—青年”三层递进：先看土地，再读历史，最后回到今天的人。

山

LANDSCAPE

山河为卷

甘肃的地貌本身就是叙事：甘南峡谷、黄土塬梁、河西戈壁与祁连雪山。站点的主视觉与插画都从地貌线条中来，让历史有可触摸的地形。

火

SPARK

星火为脉

长征、南梁、西路军三条线索，与七种精神共同构成“星火”的传递路径。页面之间用承接卡片与时间轴串联，让读者自然走向下一站。

青

YOUTH

青年为答

读到最后一页，问题应该回到自己身上：今天我怎么做。研学、宣讲、志愿讲解、数字创作与强农兴农实践，是可以立刻开始的动作。

贰 · 信息架构

九个页面，三个层次

全站共 9 个页面，均置于站点根目录，任何页面都能通过页头导航、页脚导览与页面底部承接卡片抵达其他页面，不存在孤岛页面。

层级约定：站点根目录（第 1 层）放置全部页面；css / js / images 三个资源目录为第 2 层；目录深度不超过 3 层，所有本地链接均使用相对路径，便于整站拷贝与迁移。

叁 · 技术架构

纯静态、零依赖、可离线

整站使用 HTML5 + 原生 CSS + 原生 JavaScript 手写完成，不引入任何框架、构建工具、CDN 资源或第三方字体，双击 index.html 即可完整浏览。

语义化 HTML5

header / nav / main / section / article / figure / footer 结构清晰，每页含 skip-link、面包屑与 aria 标注。

CSS 设计令牌

用 CSS 自定义属性统一管理色彩、字体、间距与阴影，一套令牌控制全站视觉，保证 9 个页面风格一致。

响应式布局

CSS Grid 与 Flexbox 实现多栏自适应，断点 1200 / 1080 / 900 / 720 / 560 px，覆盖桌面、平板与手机。

渐进增强

正文为静态 HTML，交互由无框架原生 JS 接管；禁用 JavaScript 时图文内容仍完整可读，不出现空白屏。

浏览器兼容

按 Edge 90.0 及以上版本实现与测试，同时兼容 Chrome、Firefox 等主流浏览器的近版本，不依赖实验性特性。

原创 SVG 插画

全站插画均为手写 SVG 代码绘制的矢量图，体积小、任意分辨率清晰，且不涉及任何图片版权问题。

交互模块

长征路线图联动、地标地图与筛选检索、精神谱系 Tab、传承行动勾选进度、图片灯箱、滚动入场与数字滚动。

无障碍与动效克制

支持键盘操作与可见焦点，图片均有替代文本，并遵循 prefers-reduced-motion 关闭动画；无自动播放音频。

肆 · 原创声明

哪些是我们的，哪些是大家的

本站为甘肃农业大学第五届“红色网页设计大赛”参赛作品，除标注引用的史料与领导人论述外，页面文字、版式设计、SVG 插画与代码均由参赛团队原创。

文字

除引用原文（均已标注出处）外，全部文案为团队撰写的原创表述；史实核对依据人民网、新华网、共产党员网、中国军网、中央党史和文献研究院网、甘肃党史网、甘肃农业大学官网等公开权威资料。

插画

全站所有插图均为手写 SVG 代码绘制的原创矢量插画，未使用任何网络图片、图库素材、AI 生成照片或真实历史照片，不涉及第三方著作权。

字体与素材

不加载任何网络字体，仅使用操作系统自带字体（宋体 / 黑体 / 苹方 / 微软雅黑等）回退显示；图标为内联 SVG 路径，无第三方图标库。

致敬与说明

本站为学习与纪念性质的校园文化作品，引用史料版权归原作者与发布机构所有；如对史实表述有不同意见，欢迎指正，我们将据权威资料修订。
